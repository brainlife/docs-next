# Publications

When your results are ready, publish them. A **publication** is a citable record with a DOI that describes and shares your results. "A DOI is assigned when the publication is created."

A publication can contain:

- **Groups**: sections, each with its own people, data, media and analyses.
- **Releases**: published versions of the publication's data. A release lists its data objects and the Apps used to make them.

Find publications in the sidebar:

- **My Publications**: publications you authored, contributed to, or created.
- **Public Publications**: all publications that have not been removed.

A **removed publication** is hidden from both lists and shows a **Removed** label.

---

## Create a publication

1. Open your project and select **5. Publications**.
2. Select **Publication** (the button with a plus sign).
3. In **Create publication**, fill in:

    | Field | Required |
    | :--- | :--- |
    | **Title** | Yes |
    | **Description** | Yes |
    | **Authors** (at least one) | Yes |
    | **Linked project**: the project the publication comes from | No |

4. Select **Create publication**. The DOI is assigned now, and the publication page opens.

---

## Edit a publication

On the publication page, select **Edit**. The settings have four tabs. Select **Save Changes** to keep your edits.

### Details

- **Basic information**: name, description, free-text tags, and **Topics & ontology tags** (standard topics that help others find the publication).
- **Authors & contributors**: publication-wide credits. Credits for one group are edited with that group.
- **Licensing & funding**: the **License**, and **Funding sources** (each with a **Funder** and **Grant ID**).
- **ReadMe**: Markdown shown on the publication page.

### Appearance

- **URL & banner**: the **Slug** (the short name used in the publication's URL), a **Banner URL** (image shown behind the header), and a **Hero Overlay** color.

### Groups

Groups organize a publication into sections. The tab title shows how many there are, for example **Groups (2)**. Select **Add group**, then fill in:

- **Overview**: **Group name**, **Short description** and **Detailed description**.
- **People**: the group's authors and their affiliations.
- **Data**: the files the group publishes, and **Usage notes** on how to work with them.
- **Media**: images, video, links and viewers. Choose **Add Image**, **Add Video**, **Add External Link**, **Add Link / Asset**, or an **Interactive Viewer** (pick a dataset from the project, then a web viewer for its datatype).

### Releases

A release is a published version of the data. The tab title shows how many there are, for example **Releases (1)**.

1. Select **Release** (the button with a plus sign).
2. Enter a release name and a release description.
3. Under **Data objects**, select **Data Object** to add datasets from the project.
4. Under **Group analyses**, select **Group Analysis** to attach the Jupyter notebooks used to analyze the data.
5. Add more releases later to share new subjects or updated results. The newest is marked **LATEST**.

## The publication page

Anyone can open a publication from **Public Publications** or its DOI. The page shows:

- The title, authors and affiliations, and the DOI.
- **How to Cite**: the citation to copy.
- **Publication Readme** and **About this dataset**.
- **Topics & Ontology Tags**, **License** and **Related Articles**.
- Each group's files (**Dataset Files**), with a file browser and **Download ZIP**, and its visualizations and movies.
- Releases, with "The following data objects are published as part of this release." and "The following Apps were used to generate the data in this release."

---

## Find publications

On **My Publications** and **Public Publications**, use the publication filters: search by title or description, sort by **Newest** or **A–Z**, and filter by authors, tags, datatypes and Apps.
